<objective>
Add a server-2 reconciler that recovers orphaned `published` parse_jobs whose parser result never returned. Stale `published` jobs (where `published_at` is older than a configurable threshold) are re-queued so the existing `ParseJobPublisher` re-publishes them. Closes F5 (75 orphaned jobs on staging, oldest 33 days; `listPublishableJobs` only selects `queued`/`retryable`, so a `published` orphan is never re-published).

Purpose: A `published` job whose downstream parser ack was lost is currently a permanent dead-end (attempts stays 1, queue empty, no recovery path). This restores self-healing for the ingest pipeline.

Output: A new `0012` migration adding a `reconciled` history action, a `reclaimStalePublishedJobs` repository method, a `ParseJobReconciler` class, a third reconcile `IntervalTask` in `createIngestRuntime`, two new env vars surfaced on `config.ingest`, and full coverage (real-pg repository integration + factory-injection reconciler unit + updated runtime/app/env constructors).

Scope boundary: The parser-side root cause (ack-after-persist in replay-parser-2) is a SEPARATE change and is OUT OF SCOPE here. This plan only adds the server-2 recovery loop.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-v6m-01 | Tampering / race | reclaimStalePublishedJobs concurrent with parser-result consumer or another replica | mitigate | `for update skip locked` claims disjoint batches; re-queue and history insert are one transaction; a late parser result still supersedes via the existing terminal-state guard in recordParserCompleted (status becomes succeeded → no longer `published`, so never double-reclaimed). |
| T-v6m-02 | Denial of Service | too-low staleAfterMs re-queuing in-flight jobs into a publish/parse storm | accept | Default is generous (1h, well above worst-case parse+queue-drain); value is operator-controlled config, not user input. Documented intent in the env default. |
