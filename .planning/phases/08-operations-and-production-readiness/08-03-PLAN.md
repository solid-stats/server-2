# Plan 08-03: Failed Job Retry, Manual Reparse, and Job History

## Goal

Make parser failures operationally recoverable by exposing admin-only retry and manual reparse actions and recording durable parse job history.

## Scope

- Add persistent parse job history records.
- Record history for job creation, publishing, publish failures, parser completion, parser failures, retries, and manual reparses.
- Add admin-only operations API routes for retrying failed/retryable parse jobs and creating manual reparse jobs for selected replays.
- Wire production server operations routes to the PostgreSQL ingest repository.
- Move expanded ingest routes/repository tests into adjacent same-named folders per test layout policy.
