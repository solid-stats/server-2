# Plan 08-04: OpenAPI Drift Verification and Web Compatibility

## Goal

Make stale OpenAPI artifacts fail verification and document how the future `web` client consumes the committed schema.

## Scope

- Refactor OpenAPI generation into a reusable in-memory schema builder.
- Add `openapi:verify` to compare generated schema against `openapi/server-2.openapi.json` without mutating the worktree.
- Keep `openapi:check` validating `openapi-typescript` generation from the committed artifact.
- Document cross-app expectations for `web`.

## Verification

- `pnpm run openapi:verify`
- `pnpm run openapi:check`
- Full `pnpm run verify` before commit.
