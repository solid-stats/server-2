## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-01 | Tampering | listReplays filters/cursor → SQL | mitigate | All filter/date/cursor values bind as `$n`; sort only via fixed `REPLAY_SORT.expr`; cursor decoded+validated by existing `decodeCursor` (arity/type/whitelist). No request value reaches SQL text. |
| T-17-02 | Tampering | getReplay/getReplayEvents `:id` | mitigate | `looksLikeUuid` branch — slug never cast to `::uuid` (avoids 500); `SlugOrUuidParameters` bound pattern enforced at route layer (17-02). |
| T-17-03 | Information Disclosure | participant `sid` + event actor in raw_snapshot | mitigate | Every `sid`/actor steam id routed through `maskSteamId` or omitted in `replay-mapper.ts`; unit test asserts a planted `7656119\d{10}` is masked; real-pg integration sweeps the rendered rows. |

| T-17-05 | Information Disclosure | superseded/failed parser snapshots | mitigate | Detail + events join pins `parser_results.status = 'current'`; non-current snapshots never surface. |
| T-17-SC | Tampering | npm/pip/cargo installs | accept | No package installs this phase (ROADMAP: zero new runtime deps; RESEARCH Package Legitimacy Audit = N/A). |
