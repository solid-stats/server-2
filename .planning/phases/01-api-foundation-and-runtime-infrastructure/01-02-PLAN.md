# Plan 01-02: Configuration, Logging, and Startup

<objective>
Add typed environment parsing, structured logging, and a process startup entrypoint that uses the app factory.
</objective>

<must_haves>
- D-01: runtime target remains Node 24 LTS.
- D-02: all runtime code stays ESM.
- D-10: dependencies are created outside route handlers and passed through narrow app options.
- D-17: liveness proves process health only.
</must_haves>

<threat_model>
- T-01-03 Secret leakage: env values can contain DB, RabbitMQ, and S3 credentials. Mitigation: expose a `redactConfigForLogs` helper and never log raw env or full URLs.
- T-01-04 Unclean shutdown: open sockets can hang deploys/tests. Mitigation: `src/server.ts` handles `SIGINT` and `SIGTERM`, calls `app.close()`, then closes dependency adapters.
</threat_model>
