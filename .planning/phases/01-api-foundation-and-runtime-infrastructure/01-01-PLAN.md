# Plan 01-01: Project Scaffold and App Factory

<objective>
Create the npm/TypeScript foundation and a testable Fastify app factory without process startup side effects.
</objective>

<must_haves>
- D-01: `package.json` declares Node `>=24 <25` and strict TypeScript tooling.
- D-02: `package.json` contains `"type": "module"`.
- D-03: npm is the package manager and `package-lock.json` is generated.
- D-04: `src/app.ts` exports the app factory; it does not call `listen`.
- D-05: initial source layout includes `src/config/`, `src/infra/`, `src/openapi/`, and `src/modules/`.
</must_haves>

<threat_model>
- T-01-01 Input validation bypass: Fastify v5 requires complete route schemas. Mitigation: app factory uses TypeBox provider and future route plugins must register schemas.
- T-01-02 Dependency drift: unpinned major tooling could break the foundation. Mitigation: create `package-lock.json` and pin TypeScript to 5.9.x.
</threat_model>
