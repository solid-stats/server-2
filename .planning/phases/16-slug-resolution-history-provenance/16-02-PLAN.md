    (исполняется migrate.ts как одна транзакция):
    1. `alter table <t> add column if not exists slug text;` для canonical_players, squads, rotations, replays.
    2. `create or replace function slug_base(input text) returns text language sql immutable as $$ ... $$;`
       Тело: применить multi-char `replace(replace(... lower(coalesce(input,'')) ...))`-цепочку для
       ж->zh ч->ch ш->sh щ->shch ю->yu я->ya х->kh ё->e (в ТОМ ЖЕ порядке, что CYRILLIC_TRANSLITERATION в slug.ts),
       затем `translate(...)` для одно-символьных кириллических букв, затем
       `regexp_replace(..., '[^a-z0-9]+', '-', 'g')`, затем `trim(both '-' from ...)`.
    3. Для каждой таблицы — idempotent backfill `update <t> p set slug = case when sg.base = '' then '<prefix>-' || sg.suffix when sg.dup then sg.base || '-' || sg.suffix else sg.base end from (select id, slug_base(<name_expr>) as base, substr(replace(id::text,'-',''),1,6) as suffix, count(*) over (partition by slug_base(<name_expr>)) > 1 as dup from <t>) sg where p.id = sg.id and p.slug is null;`
       name_expr: canonical_players->display_name (prefix p), squads->name (s), rotations->name (r),
       replays->`source_system || '-' || source_replay_id` (replay).
       Order-independent: суффикс присваивается КАЖДОЙ строке с не-уникальным base (window count > 1).
    4. `create unique index if not exists uq_<t>_slug on <t>(slug) where slug is not null;` и
       `create index if not exists idx_<t>_slug on <t>(slug);` для всех 4 таблиц.
    НЕ добавлять `updated_at` в rotations (вне locked-scope; provenance ротации берётся из stat-строк — Plan 04).
    Имя файла: `0006_slug_addressing.sql` (lexicographically после 0005).
