# Plan 08.1-04: Recalculation Wiring and Verification Restoration

## Goal

Connect parser completion and approved corrections to aggregate recalculation, then restore missing verification/Nyquist artifacts so the milestone can be audited again.

## Tasks

1. Load parser artifacts from S3-compatible storage on parser completion.
2. Call `ParserResultRecalculationService` after successful parser completion.
3. Replace `NoopAuditPatchRecalculator` in production with an implementation that triggers affected aggregate recalculation.
4. Add or update phase `*-VERIFICATION.md` files for phases 05-08 and 08.1.
5. Add missing `*-VALIDATION.md` artifacts or run `$gsd-validate-phase` for flagged phases.
6. Re-run milestone audit after verification passes.

## Acceptance Criteria

- Parser completion produces normalized events and aggregate updates.
- Approved stat corrections trigger real recalculation.
- Missing verification/Nyquist gaps are closed or explicitly documented as blockers.
