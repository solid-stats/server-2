# Plan 08.1-03: Persistent Auth, Requests, Moderation, and Audit Workflows

## Goal

Replace production in-memory auth/request/moderation/audit/workflow state with PostgreSQL-backed adapters that preserve v1 data across restarts.

## Tasks

1. Implement PostgreSQL auth user and session stores behind the existing auth interfaces.
2. Implement PostgreSQL request, attachment metadata, moderation, audit patch, and workflow repositories behind existing request route interfaces.
3. Wire production startup to PostgreSQL-backed adapters.
4. Preserve S3-backed attachment upload-ticket behavior.
5. Add integration tests for restart-persistent sessions, request status, moderation history, audit patches, and workflow records.

## Acceptance Criteria

- Production no longer uses in-memory auth/request/moderation/audit/workflow adapters.
- Moderation and audit records persist in existing PostgreSQL tables.
- Auth/request role gates still pass policy tests.
