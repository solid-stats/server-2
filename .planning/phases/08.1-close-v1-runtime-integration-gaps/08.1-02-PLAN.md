# Plan 08.1-02: PostgreSQL-Backed Public Stats Read Model

## Goal

Replace the production empty public stats read model with a PostgreSQL-backed read model over the aggregate tables created in earlier phases.

## Tasks

1. Implement a `PgPublicStatsReadModel` matching the existing public route contract.
2. Cover overview, players, squads, rotations, commander sides, bounty, and leaderboards with repository tests.
3. Wire the PostgreSQL read model into production `src/server.ts`.
4. Verify public stats endpoints remain anonymous and OpenAPI-compatible.

## Acceptance Criteria

- Public stats production startup no longer returns empty defaults when aggregate rows exist.
- Route tests prove anonymous access remains allowed.
- Integration tests prove PostgreSQL aggregate rows surface through public APIs.
