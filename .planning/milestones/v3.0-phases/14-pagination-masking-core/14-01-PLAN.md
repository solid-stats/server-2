## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-01 | Tampering | decodeCursor (cursor.ts) | mitigate | Structural validation of shape, `order` enum, `sort` against `allowedSorts`, `values` arity + primitive types; any failure throws BadCursorError (→400 in Plan 03), never executes raw. |
| T-14-02 | Tampering | sort whitelist -> SQL (sort.ts/keyset.ts) | mitigate | `sort`/`order` mapped to fixed server-chosen `expr` + `"ASC"`/`"DESC"` literal; seek values bound only as `$n`; no raw request value interpolated (blocks SQLi via sort/order/cursor). |
| T-14-03 | Information Disclosure | BadCursorError.message | mitigate | Error message is a fixed reason string with no echo of decoded input, so a Steam64 (or any tampered value) can never leak through an error payload (`7656119\d{10}` clean on errors). |
| T-14-SC | Tampering | npm/pip/cargo installs | mitigate | Zero new dependencies this phase (locked); no install task exists, so no package-legitimacy checkpoint is required. Buffer is a Node built-in. |
