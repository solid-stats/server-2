## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client query/cursor -> route handler | Untrusted `cursor`, `sort`, `order`, `limit`, and stray `page`/`pageSize` cross into the filter seam. |
| filter -> repository SQL | Whitelisted `expr` + `$n`-bound seek values cross into parameterized list queries. |
| DB row -> response/openapi artifact | Steam64 must be masked before it reaches a body, a cursor token, a log, or the exported contract. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-07 | Tampering | page() filter + list SQL | mitigate | decodeCursor structural validation + resolveSort whitelist; seek values bound only as `$n`; sort->fixed `expr`, order->`ASC`/`DESC` literal; no raw request value interpolated (blocks SQLi via cursor/sort/order). |
| T-14-08 | Spoofing/Tampering | cursor sort/order drift | mitigate | Reject (400) when cursor.sort/order != request sort/order (Pitfall 3), preventing a cursor resumed under a different ordering from skipping/duplicating rows. |
| T-14-09 | Denial of Service | limit / over-fetch | mitigate | `limit` schema `maximum: 100`; over-fetch is exactly `limit + 1`; no COUNT, keyset avoids deep-page OFFSET scans. |
| T-14-10 | Information Disclosure | response body / cursor token / openapi artifact | mitigate | Masking from 14-02 stays at the mapper; cursor encodes only sort value + id of public rows (never a SteamID); leak-guard sweep + `7656119\d{10}` zero-match over bodies, tokens, and the exported artifact. |
| T-14-SC | Tampering | npm/pip/cargo installs | mitigate | Zero new dependencies this phase (locked); no install task; no package-legitimacy checkpoint required. |
