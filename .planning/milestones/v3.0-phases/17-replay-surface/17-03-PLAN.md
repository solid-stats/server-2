## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → `:n` path param | crawler-controlled page index crosses into the enumerator |
| replays.slug → XML body | slug values serialized into `<loc>` content |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-10 | Tampering | XML injection via slug in `<loc>` | mitigate | `escapeXml` applied to every dynamic value in the pure builders; slugs already pattern-restricted (`^[A-Za-z0-9-]+$`) — defense in depth; unit test asserts all five entities escape. |
| T-17-11 | Tampering | `:n` page param → SQL / unbounded scan | mitigate | `:n` parsed to a non-negative integer (400 on invalid); `listReplaySitemapPage` binds `limit`/`offset` as `$n`, hard page size 50000; null slugs excluded in SQL. |
| T-17-12 | Information Disclosure | Steam64 leaking into a sitemap body | mitigate | Sitemap exposes only `replays.slug` (no participant/steam data); leak-guard sweep over sitemap routes asserts zero `7656119\d{10}` defensively. |
| T-17-13 | Information Disclosure | sitemap routes polluting / drifting the JSON contract | mitigate | Sitemap routes carry no TypeBox response schema and register outside the JSON child scope; `openapi:check` confirms they are absent from the contract. |
| T-17-SC | Tampering | npm/pip/cargo installs | accept | No package installs this phase (ROADMAP zero-new-deps; RESEARCH audit N/A). |
</threat_model>
