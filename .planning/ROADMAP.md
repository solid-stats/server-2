# Roadmap: server-2

## Overview

`server-2` v1.0 has shipped as the backend source of truth for Solid Stats. It now owns the Fastify API, PostgreSQL business state, replay ingest promotion, parser job orchestration, parser artifact persistence, aggregate statistics, Steam auth, role-gated moderation, request workflows, operations visibility, and single-VPS Docker Compose deployment path.

Future roadmap work starts with `$gsd-new-milestone`, which creates a fresh milestone-specific requirements file and phase plan.
